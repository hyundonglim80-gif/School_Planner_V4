# V4 직관성 점검 (19번 U12, 2026-10-07)

사용자의 기준: **설명서 없이 · 쉬운 말 · 같은 것은 같은 말 · 한두 번에**. 이 문서는 지금 V4를 그 기준으로 본 것이고, **코드는 고치지 않았다**.
아래 표의 번호(T·C·H·M)를 골라 말하면(예: "T1, T4, C2, H1 해 줘") 그것을 이 파일 끝 **'고른 것 → 다음 세션'** 에 U12-a, U12-b…로 더해 한 세션씩 한다.

어떻게 봤나
- 용어: 화면 글자(`src/components`, `src/features`의 단추·제목·title·안내)를 모아 같은 뜻 다른 말, 프로그램 말, 괄호로 설명을 붙인 이름을 골랐다.
- 클릭 수: `tools/inspect-clicks.mjs` - 실제 크롬(PC 1400px, teacher 계정)으로 하루 화면에서 시작해 자주 하는 일 20가지를 따라 했다.
  누르기·키를 세고, 글자 치기는 따로 적었다. 되돌리기 어려운 마지막 단추(백업 받기·구글 보내기·복원)는 누르지 않고 +1로 셌다.
  점검 계정에 명렬표가 없어 출석·발표자 뽑기는 마지막 단계를 코드대로 셌다.
- 숨은 조작: 화면에 글자·단추로 보이지 않고 설명서에만 있는 조작.

## 4. ⋮ 메뉴 - 자주 쓰는 것을 꺼내기

지금 ⋮ 메뉴는 5구역 23항목(담임 기준). 쓰는 횟수로 나누면(사용자 말·설명서·화면에 다른 길이 있는지로 짐작 - 실제 쓰는 횟수는 앱이 세지 않는다):

| 자주 (주마다 여러 번) | 가끔 (달마다) | 드물게 (학기마다·한 번) |
|---|---|---|
| 진도 관리, 출석부\*, 알림장 모아 보기\*, 라벨\*, 발표자 뽑기, 다중 선택 | 학생 누가기록, 평가 모아 보기, 자리표, 반복 일정, 미완료 일정 가져오기, 주간학습안내, 구글 캘린더로 보내기 | 시간표, 명렬표, 공유 그룹, 백업, 환경설정, 앱 설치, 사용 설명서, 교과 출결 누계, 어둡게 보기 |

\* 이미 다른 길이 있다(출석부·알림장 = 하루 화면 수업 칸 머리, 라벨 = 각 칸 ⚙️).

| 번호 | 안 |
|---|---|
| M1 | **진도 관리**를 하루 화면 수업 칸 머리(📢 알림장 · 📋 출석부 옆)에 **📘 진도** 단추로 |
| M2 | **발표자 뽑기**·**자리표**를 학급 화면 머리 단추로 (학급 화면에서 쓰는 일이라) |
| M3 | ⋮ 메뉴를 '자주'가 위로 오게 다시 묶기 - 구역 '일정 · 라벨 / 수업 / 학급 운영 / 공유·연동·백업 / 설정'은 두되 각 구역 안 차례를 위 표대로 |
| M4 | 드물게 쓰는 '앱 설치·어둡게 보기·사용 설명서'를 환경설정 안으로 (⋮를 짧게) - 단, 설명서는 '?' 단추로 머리줄에 |

## 고른 것 → 다음 세션
