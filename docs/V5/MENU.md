# V5 메뉴 · 화면 자리

2026-10-08 정함. 사용자 요청: "현재 메뉴도 기능을 기준으로 효율적으로 합치거나 분할해줘. 화면에 없어도 되는 것은 메뉴로,
자주 사용해서 화면으로 빼야 하는 것이 있으면 화면으로" + "정해야 하는 것은 네가 권장하는 방식을 따를께".

V4 자리(2026-10-08 코드: `Layout.moreMenuSections`·머리줄, `ClassScreen.TOOLS`, `DaySchedule` 수업 머리줄, `SettingsModal` 구역)와
쓰는 횟수(V4 `docs/UX-AUDIT.md` 4장 - 자주 / 가끔 / 드물게)를 보고 기능별로 다시 놓았다.
창 목록(`DESIGN.md` 7-2)의 `menu`·`classTool`·`lessonHeader` 값이 이 표를 따른다. 자리를 바꾸면 이 파일과 설명서를 같은 커밋에서 고친다.

> 지금은 V4 저장소 `docs/V5/`에 있다. P1-1에서 V5 저장소 `docs/`로 옮긴다.

## 1. 자리 규칙

1. **그 화면에서 그 일을 할 때 쓰는 단추는 그 화면에** 둔다(수업 중 = 하루 수업 머리줄, 한 주 계획 = 주간 화면).
2. **학급 일은 학급 화면 한 곳에** 모은다. ⋮의 '학급 운영' 구역을 없앤다(학급 탭 + 도구 카드 = 누르기 2번, ⋮ + 항목도 2번이라 잃는 것이 없다).
3. **⋮에는 어느 화면에서나 가끔 쓰는 것만** 둔다 → 4구역 8항목(V4는 5구역 18항목).
4. **한 기능의 설정은 그 기능 창 안에** 둔다(휴지통 자동 비우기 → 휴지통, 자동 백업 → 백업 창, 교시 이름 → 시간표 창).
5. **환경설정에는 기능에 딸리지 않은 것만**(화면 보기·알림·우리 학교·단축키·앱), 탭으로 나눈다.
6. **단축키는 모든 기능에 그대로** - 자리가 바뀌어도 V4 단축키 id와 키는 같다(사용자가 바꾼 키도 가져온다).
7. **V4에서 사용자가 정한 자리는 그대로**: 맨 위 🗑️ 휴지통(휴대폰도), 둘째 줄 토글(주말·일정·수업), 수업 종은 하루 '수업' 옆,
   명렬표는 학급 화면 안, 교사 유형은 시간표 창, 설명서는 머리줄 ?와 ⋮ 둘 다, 일정·기록 머리줄 `▼ 제목 숫자 [+ 추가] … ⚙️`.

## 2. 한눈에 — 무엇이 어디로

### 2-1. 화면으로 꺼낸 것 (자주 씀)

| 기능 | V4 자리 | V5 자리 | 까닭 |
|---|---|---|---|
| 새로 쓰기 (일정·기록·메모) | 화면마다 '+ 추가', 메모는 메모 화면 | **머리줄 '＋ 새로'**(PC) / **탭바 위 둥근 ＋**(휴대폰) → 일정·기록·메모 셋 중 고르기. 단축키 셋 | 가장 자주 하는 일 - 어느 화면에서나 한 번에. 화면마다의 '+ 추가'는 그대로 |
| 지난 일정 오늘로 가져오기 | ⋮ 일정·라벨 → 창 | **하루 화면(오늘) 일정 칸 아래 '📥 지난 일정 N개 ▸'** - 있을 때만, 펴서 골라 오늘로 | 오늘 할 일을 볼 때 쓰는 일. 메뉴를 열 까닭이 없다 |
| 반복 일정 등록 | ⋮ 일정·라벨 → 따로 된 창 | **일정 칸 안 '🔁 반복' 줄**(안 함·매일·매주 요일·매월 n째 주, 끝나는 날) | 반복은 일정의 성질 - 일정을 쓰는 칸에서 정한다(구글 캘린더처럼) |
| 기간 일정 | 라벨 속성 '기간' → 따로 된 창 | **일정 칸 '끝 날'** | 같은 까닭. 기간 일정이 한 항목이 된다(DESIGN 5-3) |
| 발표자 뽑기 | ⋮ 학급 운영 / 학급 화면 카드 | **하루 수업 머리줄 🎯**(담임) + 학급 화면 카드. 교과 전담은 교시 카드 반 도구(V4 그대로) | 수업 중에 주마다 여러 번 쓴다(UX-AUDIT '자주') |
| 여러 개 고르기 | ⋮ 일정·라벨 | ⋮ 그대로 + **일정 카드 Ctrl+누르기·Shift 범위(휴대폰 길게 누르기)로 바로 시작**, 고른 동안 화면 아래 동작 줄 | '자주'. 라벨로 보기 칩과 같은 탐색기식 누르기 |

### 3-4. ⋮ 메뉴

| 구역 | 항목 |
|---|---|
| 일정 | 🏷️ 라벨 관리 · ☑️ 여러 개 고르기 |
| 수업 | 📘 진도 관리 · ⏰ 시간표 |
| 자료 | 💾 백업 · 가져오기 · 보내기 · 🖨️ 이 화면 인쇄(인쇄할 수 있는 화면에서만) |
| 설정 | ⚙️ 환경설정 · 💡 사용 설명서 |

진도 관리는 하루 수업 머리줄 📘에도 있다(주간·월간·메모 화면에서도 열려고 ⋮에 둔다 - 규칙 3의 예외).

**⋮에서 빠진 것과 간 곳**: 반복 일정 등록 → 일정 칸 / 지난 일정 오늘로 가져오기 → 하루 화면 / 주간학습안내 → 주간 화면 /
출석부·알림장 모아 보기·발표자 뽑기·학생 기록·조사표 모아 보기·자리표·교과 출결 누계 → 학급 화면(출석부·알림장·뽑기는 하루 수업 머리줄에도) /
구글 캘린더로 보내기·백업 → 백업 · 가져오기 · 보내기 창 / 공유 그룹 관리 → 계정 칸·공간 선택 / (휴대폰) 로그아웃 → 계정 칸.

### 3-5. 계정 칸 (머리줄 사진을 누르면)
이름 · 메일 · 👥 공유 그룹(만들기·참여·관리 - P8-4 전에는 숨김) · 로그아웃.

| 탭 | 들어가는 것 |
|---|---|
| 보기 | 화면 표시 · 글자 크기 · 화면 밝기(어둡게) · 창 위치(오른쪽 칸 / 가운데 창) · 시작 화면 |

| 창 | 안에 둔 설정 |
|---|---|
| 🗑️ 휴지통 | ⚙️ 자동 비우기(끄기/7/14/30/60/90일, 기본 끄기 - V4 사용자 결정) |
| 💾 백업 · 가져오기 · 보내기 | 드라이브 자동 백업(켬·주기·남길 수), 첨부 모으기 |
| ⏰ 시간표 | 교시 이름·시각, 교사 유형, 학기·방학 |
| 🔔 수업 종 (하루 '수업' 옆) | 켬·시작/끝 종·이 기기에서 울리기 - V4 그대로 |
| 🏷️ 라벨 관리 | 일정 / 메모·기록 탭, 속성, 상위/하위, 빈 라벨 정리 - V4 그대로 |

### 3-8. 단축키 (V4 `SHORTCUT_ACTIONS` id 그대로 + 새로)

- **새 id**: `newEvent`(새 일정) · `newNote`(새 기록) · `newMemo`(새 메모) · `print`(이 화면 인쇄, 기본 Ctrl+P) · `undo`(되돌리기, 기본 Ctrl+Z - 글 칸 밖에서만).
- **id는 같고 여는 곳이 바뀜**: `recurring` → 새 일정 칸을 반복 줄을 편 채로 · `forwarding` → 오늘로 가서 '지난 일정' 줄을 편다 ·
  `group` → 계정 칸의 공유 그룹 · `calendar`·`backup` → 백업 · 가져오기 · 보내기 창의 그 탭.
- 나머지(화면 이동·날짜 이동·토글·검색·체크리스트·창 열기 모두)는 V4 그대로.

## 4. V4에서 없어지는 것

- ⋮ '학급 운영' 구역 (단축키는 그대로).
- 반복 일정 등록 창, 지난(미완료) 일정 가져오기 창, 기간 일정 창 (일정 칸·하루 화면 줄로).
- 시간표 '적용' 단추 (기간별 시간표라 필요 없다).
- 주간·년간 화면의 🖨️ 단추 (⋮·Ctrl+P로).
- 설명서 'V3와 함께 쓰기' 장 → 'V4에서 옮겨 오기'.

## 5. 설명서·점검에 미치는 것

- 설명서 '화면 구성 한눈에 보기'(머리줄·⋮ 목록)·'단축키 전체 목록'·'휴대폰에서 쓰기'·'환경설정'을 이 파일대로 고친다(P9-1).
- 창 목록 단위 테스트가 지킨다: ⋮ = 4구역 8항목, 학급 도구 카드 8개, 하루 수업 머리줄(담임·교과 각각), 환경설정 탭 다섯(V4 `inspect-more-menu` 대신).
